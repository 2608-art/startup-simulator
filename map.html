번화가 마커는 탐색용 대표 위치이며 실제 매물이나 임대료 조사 지점이 아닙니다. +%는 2026년 2분기 해당 행정동의 1층 환산임대료를 같은 구 평균과 비교한 값입니다.

위치: 서울시 상권 중심점(2023 보관본). 서초4동·잠실3동은 공개 카페 좌표(2026-09)의 평균점입니다. 가격: 서울시 지역별 임대료.

서울시·JUSO 2015 시군구 경계의 단순화본입니다. 최신 법정·지적 경계가 아닌 탐색용 참고입니다. 구별 통계는 서울시 공식 자치구 코드로 연결하며, 기준분기와 출처는 정보 패널에 표시합니다.

비교안 저장·불러오기

선택한 안의 저장된 조건을 그대로 복사합니다. 원본은 바뀌지 않습니다.

평수·층수·금액·예산을 바꾼 뒤 저장하면 이 복사본에만 반영됩니다.

새로고침 후에도 삭제된 안을 골라 복구할 수 있어요. 같은 이름이 있으면 ‘(복원)’을 붙여 보관합니다.

이 브라우저에 최대 50개 저장됩니다. 선택 목록(예산 밖 포함), 공통·개별 면적과 층, 직접 입력 금액, 예산·필터·정렬을 함께 보관합니다. 저장된 안은 자동으로 덮어쓰지 않으며, 추정금액은 불러올 때 현재 자료로 다시 계산합니다.

원본 · 복사본 비교

두 안의 조건과 예상 비용을 나란히 살펴보세요.

복사본 칸에서 바로 수정하세요. 입력하면 차이가 갱신되고, ‘복사본에 저장’을 눌러야 저장된 안에 반영됩니다. 직접 입력한 금액은 평수·층수를 바꿔도 유지됩니다. 수정 중에는 같은 항목도 표시해요.

표에서 번화가별 평수와 층을 바꾸세요. 처음 담은 곳은 공통 평수·층으로 시작합니다(범위 모드 또는 면적 미입력 시 20평). 공통 모드로 돌아가도 개별 조건은 보관됩니다.

어느 정도 크기의 매장을 생각하세요?

평

12.5평처럼 소수도 입력할 수 있어요. 입력하면 모든 번화가의 가격이 함께 바뀝니다.

모든 번화가에 같은 층별 비율을 적용하는 모의 비교예요. 지하 2층 이하는 자료가 없어 지원하지 않습니다.

모두 1층 · 33~66㎡(약 10~20평) · 보증금은 월세 12개월분 가정

최대 예산

빈칸은 제한 없음 · 전체 보기에서도 예산 여유·초과액을 표시합니다. 필터를 켜면 입력한 두 예산을 모두 충족하는 곳만 표시합니다. 현재 표의 직접 입력 금액을 우선 적용하며, 추정 범위는 상한까지 예산 이내인 곳만 표시해요. 평수·층 수정은 입력을 마치면 반영됩니다.

추정한 값으로, 실제 수치와 차이가 있을 수 있습니다.

임대료 추정 기준 · 출처

번화가 주변 행정동 평균을 적용합니다. 구 대비 차이는 각 번화가가 속한 구의 1층 평균 기준입니다. 권리금·관리비·VAT·중개비는 별도 가산하지 않았습니다.

층별 가격 계산 기준

서울 전체 중대형 상가의 층별 비율을 각 번화가의 1층 단가에 공통 적용합니다. 번화가·카페별 실제 층 시세가 아니며, 지역 단가와 조사 표본·기준분기가 다릅니다. 구 평균 대비 비율은 1층 기준을 유지합니다.
